# 🪨📄✂️ Stone Paper Scissors

A simple and fun browser-based Stone Paper Scissors (Rock Paper Scissors) game built using HTML, CSS, and JavaScript. Play against the computer and keep track of your score!

## 🎮 Live Demo

[Play the game here](https://abhinawsingh242.github.io/StonePaperScissors/)

## 📸 Preview

*(Add a screenshot of your game here once you have one)*

## ✨ Features

- Play against a computer opponent with random choice generation
- Real-time score tracking for both player and computer
- Instant win/lose/draw feedback with visual cues
- Clean and responsive user interface
- Built with vanilla JavaScript — no frameworks or libraries

## 🛠️ Tech Stack

- **HTML** – Structure of the game
- **CSS** – Styling and layout
- **JavaScript** – Game logic and interactivity

## 🚀 How to Play

1. Clone this repository:
```bash
   git clone https://github.com/Abhinawsingh242/StonePaperScissors.git
```
2. Navigate into the project folder:
```bash
   cd StonePaperScissors
```
3. Open `index.html` in your browser
4. Click on **Stone**, **Paper**, or **Scissors** to play against the computer
5. Watch your score update as you play!
